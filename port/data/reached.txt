# Tables that only pointers reach, for tools/port/gen_data.py (docs/port/DATA.md 7). No symbol describes them, so
# without a rule the loader leaves them in the ROM's byte order and the N64 layout (the report's "undescribed" lines
# that are not text). At every load of its image the loader follows each rule's pointers: a table of a type with
# pointers, or with a host layout of its own, is converted to host storage of its own and the pointer rewritten to
# it; any other is swapped in place. The loader reads the counts from the ROM; nothing here holds ROM data.
#
#   ROOT    TYPE    COUNT
#
# ROOT: a table of pointers with storage of its own (each of its pointers), or Tag.field: that pointer field of every
# element an earlier rule with TYPE Tag reaches. TYPE: a struct tag of the game C (from its DWARF), or u8, s8, u16,
# s16, u32, s32 or f32, optionally [N]. COUNT: N; `until FIELD` (the element whose FIELD is zero ends the table and is
# part of it); `parent FIELD` (that field of the element holding the pointer); TABLE[i] (element i of a table of
# integers, for the root's pointer i).
